API reference

@tunn/oxygen is a WebGL 2 engine for creative sites, built on three.js. Each section lists the public exports of one area, shows how they fit together and, where it matters, runs a live demo against the real engine. Deeper guides live in docs/ in the repository.

Overview

The package is ESM only and ships JavaScript with declarations. Importing the root entry is safe in Node and during SSR. Creating a renderer, starting the frame loop and constructing input or audio adapters need a browser.

DependencyVersionRequired
three~0.186.1Yes
zod^4.0.0Yes
@dimforge/rapier3d-compat~0.21.0Only for PhysicsWorld
 
npm install @tunn/oxygen three zod
npm install @dimforge/rapier3d-compat   # only for PhysicsWorld

The package is not on npm yet. Depend on the repository pinned to a commit, as described in the README. Rigid body physics is imported from @tunn/oxygen/physics; everything else comes from the root entry.

Quick start

A scene with post-processing and adaptive quality. startLoop() must run before the render function does anything, and warmUp() compiles every program before the first frame. 

import * as THREE from 'three';
import {
  BloomPass, ColorGradePass, PostStack, QualityManager, createPipeline, detectGPU, onFrame, onResize,
  setRenderFunction, stage, startLoop,
} from '@tunn/oxygen';

startLoop();
const pipeline = createPipeline(document.querySelector<HTMLElement>('.stage')!, { hdr: true });
const camera = new THREE.PerspectiveCamera(45, stage.width / stage.height, 0.1, 100);
camera.position.z = 5;
onResize(() => {
  camera.aspect = stage.width / stage.height;
  camera.updateProjectionMatrix();
});

const post = new PostStack(pipeline.renderer);
post.add(new BloomPass({ threshold: 0.9 }));
post.add(new ColorGradePass({ toneMapping: 'aces', outputSRGB: true }));
pipeline.setPost(post);

const quality = new QualityManager({
  levels: [{ name: 'low', dpr: 1 }, { name: 'high', dpr: 2 }],
  initial: { tier: detectGPU(pipeline.renderer.getContext()).tier },
});
quality.bindPipeline(pipeline);
quality.start();

const mesh = new THREE.Mesh(
  new THREE.TorusKnotGeometry(1, 0.3, 200, 24),
  new THREE.MeshStandardMaterial({ emissive: 0x3d7bff, emissiveIntensity: 4 }),
);
pipeline.scene.add(mesh, new THREE.HemisphereLight(0xffffff, 0x222222, 1));
onFrame((_time, delta) => (mesh.rotation.y += delta * 0.0005));
await pipeline.warmUp(camera);
setRenderFunction(() => pipeline.render(camera));

Frame loop

One RAF loop drives everything. Each frame runs tweens first, then the four phases in order, then the render function, then postRender. frame.delta is in milliseconds and capped at 200.

ExportPurpose
startLoop(): voidStarts the loop and installs the viewport and pointer listeners. Idempotent.
stopLoop(): voidCancels the next frame. Subscriptions stay registered, so startLoop() resumes them.
onFrame(cb, phase?): () => voidcb(time, delta) runs every frame. phase is 'loop' (default), 'afterLoops', 'beforeRender' or 'postRender'.
setRenderFunction(fn): () => voidInstalls the one render callback. The returned cleanup clears it only if it is still installed.
frame{ time, delta, count, hzMultiplier }, updated each frame.
ComponentA THREE.Group whose startRender loops run only while it and its ancestors are visible.

Tweens and DOM

tween animates numeric fields of any object. Eases are named: any Penner ease such as easeOutCubic or easeInOutQuad, linear, or a custom cubic-bezier registered with addCustomEase. A new tween on the same object replaces the earlier ones unless it sets multiTween. Decorative tweens finish at once under reduced motion; pass 'essential' as the last argument when the motion carries meaning.

ExportPurpose
tween(object, props, time, ease?, delay?, motion?)Returns a Tween. time and delay are in ms.
TweenChainable: onUpdate(k => …), onComplete(fn). Methods: promise(), pause(), resume(), stop().
tweenUniform(uniforms, name, value, time, ease?, delay?)Tweens a float uniform in uniforms[name].value.
clearTween(object)Stops every tween on the object.
addCustomEase(name, 'cubic-bezier(x1, y1, x2, y2)')Registers a named ease. Registering an existing name is ignored.
delay(ms), defer()Promises that resolve after a timeout or on the next animation frame.
dom(el).set(props)Applies x, y, scale, scaleX and opacity immediately and cancels running DOM tweens on that element.
dom(el).tween(props, time, ease, delay?)Tweens the same properties and returns a promise. clear: true removes the inline transform at the end. x and y take numbers (px) or strings such as '50%', '10vw'.

Live demo: numeric and DOM tweens

The card uses dom(el).tween; the bar uses a tween on a plain object and reads it in onUpdate. With Reduce, or with System when the OS asks for less motion, decorative tweens jump straight to their end values. 

const meter = { value: 0 };
tween(meter, { value: 1 }, 900, 'easeInOutCubic').onUpdate(() => {
  bar.style.transform = `scaleX(${meter.value})`;
});
void dom(card).tween({ x: 160, opacity: 0.6 }, 600, 'easeOutBack');

Events and state

One process-wide event bus and a key/value store. setState emits state:<name> only when the value changes, so bindState can drive the UI from state without polling.

ExportPurpose
emit(name, value?)Calls the listeners of name synchronously.
listen(name, cb)Subscribes. Returns the unsubscribe function.
setState(name, value)Stores the value and notifies bindState listeners when it differs from the previous value.
getState(name)The stored value, or undefined.
requireState(name)The stored value; throws if it was never set.
bindState(name, cb)Calls cb now if a value exists, then on every change. Returns the unsubscribe function.
whenState(name)Resolves with the first value, immediately if one is already stored.

Live demo: bus and bound state

Pings received: 0 
listen<number>('Demo/ping', count => { pingCount.textContent = String(count); });
emit('Demo/ping', pings);

setState('demo.gain', 0.5);
bindState<number>('demo.gain', value => { gainValue.textContent = value.toFixed(2); });
gain.addEventListener('input', () => setState('demo.gain', Number(gain.value)));

Pointer input

PointerTracker follows one element's primary pointer. It reports CSS pixels, normalised device coordinates, a smoothed position that eases each frame, velocity, and tap and drag gestures. Call update(delta) once per frame; destroy() removes its listeners.

ExportPurpose
new PointerTracker(element?, options?)Defaults to window. Options: velocitySmoothing (0.05 s), follow (0.15), dragThreshold (6 px), tapMaxMs (300).
.on(event, listener)'tap', 'dragStart', 'drag' or 'dragEnd'. Returns the unsubscribe function.
.position, .ndc, .uvCSS px from the top-left, −1…1 with y up, and 0…1 with y up.
.smoothed, .velocity, .speedEased position, smoothed px/s, and the magnitude of the velocity.
.down, .inside, .dragPressed, hovered and drag state (active, start, delta).
update(deltaMs), destroy()Per-frame easing; removes listeners.
pointerToPlane(ndc, camera, plane, out?)The point where the ray through ndc meets the plane, or null.
Interaction3D, interaction3d()Raycasts the pointer against meshes and reports hits.

Live demo: pointer tracker

Move or drag over the pad.

const tracker = new PointerTracker(pad);
tracker.on('tap', () => { taps += 1; });
onFrame((_time, delta) => {
  tracker.update(delta);
  dot.style.transform = `translate(${tracker.smoothed.x}px, ${tracker.smoothed.y}px)`;
});

Render pipeline

createPipeline owns a WebGL 2 canvas, an MSAA scene buffer (half-float with hdr), a composite or post stack, and pixel-space overlays. A pipeline in container mode sizes to a host element, which suits embedded scenes. dispose() releases everything the pipeline owns and is idempotent; rendering after it throws DisposedError.

ExportPurpose
createPipeline(parent, options?)Options: sizeMode ('viewport' default, or 'container'), clearColor, samples (default 4), hdr (default false), flipMirroredWinding (default true).
pipeline.scene, uiScene, uiCamera, beforePassesSceneScene graphs. uiScene with uiCamera is the overlay pass; beforePassesScene is a pixel-space overlay drawn into the scene buffer before the composite.
pipeline.size, dpr, statusLogical size, current pixel ratio, and 'ready' | 'lost' | 'disposed'.
render(camera)Draws one frame.
setPost(stack | null), setComposite(material)Replaces the final pass. The caller owns the stack; detach it before disposing it.
setPixelRatio(dpr)Resizes the canvas, scene buffer and post stack. Used by adaptive quality.
addPreRender(fn)Runs off-screen work before the main pass each frame.
warmUp(camera)Compiles every program and uploads every texture and geometry, including hidden objects. Run it while the loader is up.
onContextChange(listener)Reports context loss and restoration. GPU-only simulation state may need reseeding.
registerOffscreenPass(object)Includes a full-screen pass that renders outside the scenes in warmUp.
createAccessiblePipeline(host, fallback, options?)Returns { pipeline, reason, dispose }. Shows fallback when WebGL 2 is unavailable or lost, and hides the canvas from assistive tech.

Live demo: embedded pipeline with teardown

const pipeline = createPipeline(host, { sizeMode: 'container', clearColor: '#14161c' });
void pipeline.warmUp(camera);
const offRender = setRenderFunction(() => pipeline.render(camera));

// On unmount, release every subscription and the pipeline itself:
offRender();
pipeline.dispose();

Shaders and materials

Shaders live in one bundle file. A plain entry is a chunk that other sources pull in with #require(name). Entries with #!SHADER: Name.vs and Name.fs become shader programs. #test condition blocks are kept or dropped by an evaluator you supply. createShaderMaterial builds a GLSL ES 3.00 RawShaderMaterial and provides time, timeScale, resolution, cameraQuaternion and normalMatrixWorld.

ExportPurpose
loadShaderLibrary(url)Fetches and registers a bundle.
registerShaderBundle(text), registerShaderSource(name, code)Registers bundle text or one named chunk without fetching.
addShaderTests(evaluator)Resolves #test conditions to true or false. Return undefined for a condition you do not handle; an unknown condition makes loading throw.
createShaderMaterial(name, uniforms, options?)Builds the material. Transparent materials use straight alpha; opaque ones disable blending.
hasShader(name), getShaderSource(name)Lookup. An unknown name throws ShaderNotFoundError.
globalUniforms, attachWorldNormalMatrix(mesh)Shared uniforms and a helper that supplies normalMatrixWorld to a mesh.
 
addShaderTests((condition, { isMobile }) => (condition === 'quality.high' ? !isMobile : undefined));
await loadShaderLibrary('shaders/library.glsl');
const material = createShaderMaterial('Gradient', { uAlpha: { value: 0 } }, { transparent: true });

Post-processing

PostStack chains passes over the scene buffer. Each pass is a PostPass with its own options and an enabled flag. The stack is attached with pipeline.setPost.

ExportPurpose
PostStack(renderer)add(pass) appends a pass and returns it.
BloomPassThreshold, knee, intensity, radius and mip levels.
ColorGradePasstoneMapping ('none', 'reinhard', 'aces'), outputSRGB, exposure, contrast, saturation.
LensPasschromaticAberration, vignette, grain.
FXAAPass, ShaderPass, TransitionPassAnti-aliasing, a custom shader pass, and screen transitions.

The full option reference is in docs/post.md. For a running example, open the post-processing demo.

GPU particles

GPUParticles advects particles on the GPU with curl noise and attractors. The particles demo runs up to 262k particles. GPUSimulation is the lower-level simulation it is built on, and NOISE_GLSL exports the noise chunk for custom shaders.

ExportPurpose
GPUParticlesParticle system; options cover count, emitter shape, curl and attractors.
GPUSimulation, NOISE_GLSLSimulation core and the shared noise GLSL.
particleTextureSize(count), seedParticles, sampleEmitter, randomDirectionTexture sizing and seeding helpers.

Reference: docs/particles.md. Live example: GPU particles demo.

Physics

Closed-form springs and Verlet simulation are in the root entry. Rigid bodies are in the subpath, so applications that do not need them never load Rapier.

ExportEntryPurpose
Spring, VectorSpring, springSteprootDamped springs for scalars and vectors. Frame-rate independent.
VerletWorld, createRope, createCloth, ClothGeometryrootPosition-based simulation with colliders, ropes and cloth.
PhysicsWorld@tunn/oxygen/physicsRapier rigid bodies. Requires @dimforge/rapier3d-compat.
 
import { PhysicsWorld } from '@tunn/oxygen/physics';
import { Spring } from '@tunn/oxygen';

Reference: docs/physics.md. Live example: physics demo.

Router

Router maps paths to views and runs each navigation as an ordered, abortable transition. A newer navigation aborts an older one. Views are created once per route and may load their code lazily.

ExportPurpose
new Router(options)Options: routes, notFound, mode ('history' or 'hash'), base, transition ('out-in' or 'cross'), interceptLinks, prefetch, focusSelector, root.
start(), navigate(target, { replace?, force? }), back()Start on the current location, navigate (resolves to a NavigationResult), and go back in history.
path(name, params?), href(name, params?), resolve(target)Build a path or link for a named route, or match a target.
busy, destroy()Whether a transition is running; tears the router down.
compilePath, matchPath, buildPathPath pattern helpers used by the router.
RouteNotFoundErrorThrown for unmatched paths when no notFound route is set.

Reference: docs/router.md. Live example: page transitions demo.

Scroll and story

VirtualScroll turns wheel, touch and keyboard input into an eased scroll position. ScrollStory stacks StoryScenes top to bottom, drives the camera from that position and moves the matching DOM sections with it.

ExportPurpose
VirtualScroll(options)scrollTo(value, time?, ease?), setTarget(value), targetY, reset(), destroy().
scrollStateCurrent { y, delta, max, ready }.
ScrollStory(pipeline, root)load(configs, onProgress), start(), scenes, scrollToTop().
StorySceneSubclass with super(name, order). Override create, animateIn, animateOut and related hooks.

Each scene's height is given in viewport heights and eases toward mobileHeight as the viewport narrows. The story publishes Story/scrollY, Story/visibleScenes and related state. Emit Global/loaderFinished when the intro ends. The guide shows a full story in docs/guide.md.

Assets

Textures are cached one per path and alpha mode. Compressed textures and Draco meshes are opt-in. A GLTFAssets scope owns everything it loads, so disposing the scope releases it.

ExportPurpose
getTexture, getRepeatTexture, getKTX2Texture, initTextures, pendingTextureLoadsCached texture loading, KTX2 transcoder setup and a promise for in-flight loads.
loadGeometry, configureGeometry, loadSkinAnimationLoads .bin (Draco) and BufferGeometry JSON, and skeletal animation.
GLTFAssets({ renderer, dracoDecoderPath?, ktx2TranscoderPath? })load(url, { signal, timeoutMs }) returns a handle; dispose() releases the scope.
createLoadProgress(weights, onChange)Weighted progress across stages. The value never decreases.
ConfigStoreTyped reads from a flat key/value document. Wrong types throw ConfigValueError.
 
const assets = new GLTFAssets({ renderer: pipeline.renderer, dracoDecoderPath: '/decoders/draco/' });
const controller = new AbortController();
const asset = await assets.load('/models/scene.glb', { signal: controller.signal, timeoutMs: 30000 });
pipeline.scene.add(asset.gltf.scene);
// On unmount: assets.dispose();

Audio

A Web Audio manager with named tracks and effect chains. It resumes on the first user gesture, ducks when the page loses focus, and disposes every track it owns.

ExportPurpose
audioManager(), AudioManagerProcess-wide singleton. dispose() closes its context; the accessor can then create a fresh manager.
AudioTrack, EffectChainA playable source and its effect graph. Duplicate IDs are rejected.
crossfadeMix(progress, bounds?)Maps a cross-fade progress value to the mix between two tracks.
RoundRobin, preferredAudioFormat()Cycles through variants; picks 'ogg' or 'mp3' for the browser.
AudioLoadErrorA track failed to fetch or decode.

Text

MSDF text from BMFont-style JSON metadata, laid out into quad buffers.

ExportPurpose
configureFonts({ fontPath })Sets the base path for font files.
loadFont(name)Loads a font by name; resolves to a Font.
layoutText(font, options)Returns TextBuffers for the quad geometry.
karaokeBuffer(animation, words)Per-word animation data for karaoke-style reveals.

Quality and motion

Classify the GPU once, then let QualityManager move between the levels you define as frame times change. Each level has a name and a pixel ratio, and can carry any other fields your scene needs. The reduced-motion policy is global and follows the OS unless you set it.

ExportPurpose
detectGPU(gl?)Returns { renderer, vendor, tier, reason, mobile, webgl2 }. tier is 0 to 3.
classifyGPU(renderer, hints)Pure tier classification from a renderer string.
QualityManager(options)bindPipeline(pipeline), onChange(listener), set(index), start(), stop(), level.
AdaptiveQuality, levelForTier(tier, count)The frame-time controller and the tier-to-level mapping.
prefersReducedMotion()Current policy as a boolean.
setMotionPreference('system' | 'reduce' | 'full')Explicit user control. 'system' follows the OS.
onMotionChange(listener)Calls the listener now and on change. Returns the unsubscribe function.

Application-authored animation and shaders must check prefersReducedMotion() themselves. The engine does not disable keyboard navigation or replace semantic HTML.

Errors

Every failure the engine raises is a typed error, so callers can branch on instanceof.

ErrorRaised when
AssetLoadErrorAn asset fails to load. The message names the URL.
ShaderNotFoundErrorA shader name is not registered.
ConfigValueErrorA config read has the wrong type.
GeometryFormatErrorA geometry file has an invalid format.
UnsupportedFeatureErrorThe browser lacks a required feature, such as WebGL 2.
MissingDependencyErrorAn optional peer, such as Rapier, is not installed.
RouteNotFoundErrorNo route matches and no notFound route is set.
DisposedErrorAn object is used after dispose().
AudioLoadErrorAn audio track fails to fetch or decode.
