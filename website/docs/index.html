Meet Oxygen.Làm quen Oxygen.

Your idea, three.js, and a toolkit that connects the pieces. Here is how to get from a local checkout to your first frame.Ý tưởng của bạn, three.js và bộ công cụ kết nối mọi thành phần. Bắt đầu từ bản sao cục bộ đến khung hình đầu tiên.

A note on the betaVề phiên bản beta

Oxygen is currently a private, unpublished package. These instructions use a local repository checkout. Public npm installation is not available yet.Oxygen hiện là package riêng tư, chưa phát hành trên npm. Hướng dẫn này dùng bản sao repository cục bộ.

01 / SETUP

Start with a local checkout.Bắt đầu từ bản sao cục bộ.

Use Node.js 24 or 26 and an authorized checkout of the Oxygen repository. Install the locked dependencies, then start the website development server.Dùng Node.js 24 hoặc 26 và bản sao repository Oxygen có quyền truy cập. Cài dependency theo lockfile rồi chạy website.

Terminal · repository root
npm ci
npm run dev:website

The development server prints the local URL. The homepage, documentation, reference and demos are served together from website/.Dev server sẽ in địa chỉ truy cập. Trang chủ, hướng dẫn, tài liệu API và demo được phục vụ từ website/.

three~0.186.1
zod^4.0.0
Rapier (optional)(tùy chọn)~0.21.0

For a separate application, run npm run build and npm pack --ignore-scripts in this repository, then install the resulting tarball with its peers. Rigid-body physics is a separate import: @tunn/oxygen/physics.Với ứng dụng riêng, chạy npm run build và npm pack --ignore-scripts tại repository này, rồi cài tarball cùng peer dependency. Rigid-body physics có import riêng: @tunn/oxygen/physics.

02 / CREATE

Your first scene.Scene đầu tiên của bạn.

Give the canvas a positioned container with an explicit size. Initialize browser-only code after the host element exists. Container mode follows the size of its parent.Tạo vùng chứa có định vị và kích thước rõ ràng. Khởi tạo code trình duyệt sau khi phần tử host đã tồn tại. Chế độ container sẽ theo kích thước phần tử cha.

index.html
<div id="scene" style="position: relative; height: 420px"></div>
main.ts
import * as THREE from 'three';
import {
  createPipeline, onFrame, prefersReducedMotion,
  setRenderFunction, startLoop,
} from '@tunn/oxygen';

const host = document.getElementById('scene');
if (!host) throw new Error('Scene host not found');

startLoop();
const pipeline = createPipeline(host, { sizeMode: 'container' });
const camera = new THREE.PerspectiveCamera(45, 1, 0.1, 100);
camera.position.z = 4;

const geometry = new THREE.TorusKnotGeometry(0.8, 0.25, 128, 16);
const material = new THREE.MeshNormalMaterial();
const mesh = new THREE.Mesh(geometry, material);
pipeline.scene.add(mesh);

const offFrame = onFrame((_time, delta) => {
  if (!prefersReducedMotion()) mesh.rotation.y += delta * 0.001;
});
const offRender = setRenderFunction(() => {
  camera.aspect = pipeline.size.width / pipeline.size.height;
  camera.updateProjectionMatrix();
  pipeline.render(camera);
});

03 / OWNERSHIP

Create deliberately. Clean up explicitly.Khởi tạo có chủ đích. Giải phóng rõ ràng.

The pipeline owns its renderer and render targets. Your application owns the geometry and materials it adds. Keep the cleanup functions returned by frame subscriptions.Pipeline sở hữu renderer và render target. Ứng dụng sở hữu geometry, material được thêm vào. Giữ các hàm cleanup từ subscription khung hình.

On component unmount
offFrame();
offRender();
pipeline.dispose();
geometry.dispose();
material.dispose();

For meaningful content, use createAccessiblePipeline with semantic fallback HTML. Application-authored animations should consult prefersReducedMotion().Với nội dung có ý nghĩa, dùng createAccessiblePipeline cùng HTML dự phòng. Hoạt ảnh do ứng dụng viết cần kiểm tra prefersReducedMotion().
