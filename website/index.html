No opinionated UI framework lock-in. Oxygen handles the frame loop, render pipeline, post passes, asset lifecycle and input gestures so you can focus entirely on what dazzles on screen. Không ép buộc framework UI. Oxygen quản lý toàn diện vòng lặp khung hình, pipeline render, hậu xử lý HDR, nạp tài nguyên và tương tác con trỏ để bạn tập trung sáng tạo trên canvas.

  • Deterministic Frame LoopVòng lặp khung hình tất định Phased callbacks (input → update → physics → render) with zero garbage collection spikes.Các pha callback rõ ràng tránh triệt để tình trạng đơ giật do Garbage Collection.

  • First-Class AccessibilityHỗ trợ tiếp cận toàn diện Built-in reduced motion synchronisation and semantic DOM fallbacks for screen readers.Tự động tôn trọng cấu hình reduced-motion hệ điều hành và fallback DOM trực quan.

first-scene.ts 
import * as THREE from 'three';
import {
  createPipeline, PostStack, BloomPass,
  ColorGradePass, onFrame, startLoop,
} from '@tunn/oxygen';

// 1. Initialize deterministic engine loop
startLoop();

// 2. Create HDR WebGL 2 pipeline with container sizing
const host = document.getElementById('scene')!;
const pipeline = createPipeline(host, { hdr: true, samples: 4 });

// 3. Attach cinematic post-processing stack
const post = new PostStack(pipeline.renderer);
post.add(new BloomPass({ threshold: 0.8, intensity: 1.2, radius: 0.75 }));
post.add(new ColorGradePass({ toneMapping: 'aces', outputSRGB: true }));
pipeline.setPost(post);

// 4. Add your three.js objects & frame callback
const camera = new THREE.PerspectiveCamera(45, 1, 0.1, 100);
camera.position.z = 5;

const mesh = new THREE.Mesh(
  new THREE.TorusKnotGeometry(1, 0.3, 180, 24),
  new THREE.MeshStandardMaterial({ color: '#00f5a0', roughness: 0.2 })
);
pipeline.scene.add(mesh);

onFrame((_time, delta) => {
  mesh.rotation.y += delta * 0.0008;
  pipeline.render(camera);
});
