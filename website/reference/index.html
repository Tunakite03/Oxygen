API referenceTài liệu API

@tunakite03/oxygen is a WebGL 2 engine for creative sites, built on three.js. Each section lists the public exports of one area, shows how they fit together and, where it matters, runs a live demo against the real engine. Deeper guides live in docs/ in the repository. @tunakite03/oxygen là engine WebGL 2 cho các trang web sáng tạo, xây trên three.js. Mỗi mục liệt kê export công khai của một khu vực, cho thấy các phần kết hợp với nhau và, khi cần, chạy demo trực tiếp trên engine thật. Hướng dẫn chi tiết hơn nằm trong docs/ của repository.

OverviewTổng quan

The package is ESM only and ships JavaScript with declarations. Importing the root entry is safe in Node and during SSR. Creating a renderer, starting the frame loop and constructing input or audio adapters need a browser. Gói chỉ hỗ trợ ESM và đi kèm JavaScript cùng khai báo kiểu. Import root entry an toàn trong Node và khi SSR. Tạo renderer, khởi động vòng lặp khung hình, hay tạo adapter input hoặc âm thanh đều cần trình duyệt.

Quick startBắt đầu nhanh

A scene with post-processing and adaptive quality. startLoop() must run before the render function does anything, and warmUp() compiles every program before the first frame. Một cảnh có hậu xử lý và chất lượng thích ứng. startLoop() phải chạy trước khi render function làm bất cứ việc gì, và warmUp() biên dịch mọi program trước khung hình đầu tiên. 

import * as THREE from 'three';
import {
  BloomPass, ColorGradePass, PostStack, QualityManager, createPipeline, detectGPU, onFrame, onResize,
  setRenderFunction, stage, startLoop,
} from '@tunakite03/oxygen';

startLoop();
const pipeline = createPipeline(document.querySelector<HTMLElement>('.stage')!, { hdr: true });
const camera = new THREE.PerspectiveCamera(45, stage.width / stage.height, 0.1, 100);
camera.position.z = 5;
onResize(() => {
  camera.aspect = stage.width / stage.height;
  camera.updateProjectionMatrix();
});

const post = new PostStack(pipeline.renderer);
post.add(new BloomPass({ threshold: 0.9 }));
post.add(new ColorGradePass({ toneMapping: 'aces', outputSRGB: true }));
pipeline.setPost(post);

const quality = new QualityManager({
  levels: [{ name: 'low', dpr: 1 }, { name: 'high', dpr: 2 }],
  initial: { tier: detectGPU(pipeline.renderer.getContext()).tier },
});
quality.bindPipeline(pipeline);
quality.start();

const mesh = new THREE.Mesh(
  new THREE.TorusKnotGeometry(1, 0.3, 200, 24),
  new THREE.MeshStandardMaterial({ emissive: 0x3d7bff, emissiveIntensity: 4 }),
);
pipeline.scene.add(mesh, new THREE.HemisphereLight(0xffffff, 0x222222, 1));
onFrame((_time, delta) => (mesh.rotation.y += delta * 0.0005));
await pipeline.warmUp(camera);
setRenderFunction(() => pipeline.render(camera));

Frame loopVòng lặp khung hình

One RAF loop drives everything. Each frame runs tweens first, then the four phases in order, then the render function, then postRender. frame.delta is in milliseconds and capped at 200. Một vòng RAF điều khiển mọi thứ. Mỗi khung hình chạy tween trước, rồi bốn phase theo thứ tự, sau đó render function, cuối cùng là postRender. frame.delta tính bằng mili giây và bị giới hạn tối đa 200.

startLoop(): void Starts the loop and installs the viewport and pointer listeners. Idempotent.Khởi động vòng lặp và cài listener cho viewport và con trỏ. Gọi nhiều lần vẫn an toàn.
stopLoop(): void Cancels the next frame. Subscriptions stay registered, so startLoop() resumes them.Hủy khung hình kế tiếp. Các subscription vẫn được giữ, nên startLoop() tiếp tục chúng.
onFrame(cb, phase?): () => void cb(time, delta) runs every frame. phase is 'loop' (default), 'afterLoops', 'beforeRender' or 'postRender'.cb(time, delta) chạy mỗi khung hình. phase là 'loop' (mặc định), 'afterLoops', 'beforeRender' hoặc 'postRender'.

Tweens and DOMTween và DOM

tween animates numeric fields of any object. Eases are named: any Penner ease such as easeOutCubic or easeInOutQuad, linear, or a custom cubic-bezier registered with addCustomEase. A new tween on the same object replaces the earlier ones unless it sets multiTween. Decorative tweens finish at once under reduced motion; pass 'essential' as the last argument when the motion carries meaning. tween hoạt hóa các trường số của bất kỳ object nào. Easing được đặt tên: mọi ease Penner như easeOutCubic hoặc easeInOutQuad, linear, hoặc một cubic-bezier tùy chỉnh đăng ký bằng addCustomEase. Tween mới trên cùng object sẽ thay thế các tween trước đó, trừ khi đặt multiTween. Tween trang trí kết thúc ngay khi bật giảm chuyển động; truyền 'essential' làm tham số cuối khi chuyển động mang ý nghĩa.

Events and stateSự kiện và trạng thái

One process-wide event bus and a key/value store. setState emits state:<name> only when the value changes, so bindState can drive the UI from state without polling. Một event bus và kho key/value dùng chung cho cả tiến trình. setState chỉ phát state:<name> khi giá trị thay đổi, nên bindState có thể điều khiển UI từ state mà không cần polling.

listen(name, cb) Subscribes. Returns the unsubscribe function.Đăng ký. Trả về hàm hủy đăng ký.
setState(name, value) Stores the value and notifies bindState listeners when it differs from the previous value.Lưu giá trị và thông báo cho các listener bindState khi giá trị khác với giá trị trước.

Pointer inputĐầu vào con trỏ

PointerTracker follows one element's primary pointer. It reports CSS pixels, normalised device coordinates, a smoothed position that eases each frame, velocity, and tap and drag gestures. Call update(delta) once per frame; destroy() removes its listeners. PointerTracker theo dõi con trỏ chính của một phần tử. Nó báo cáo tọa độ CSS px, tọa độ chuẩn hóa (NDC), vị trí đã làm mượt (ease mỗi khung hình), vận tốc, và các cử chỉ chạm và kéo. Gọi update(delta) mỗi khung hình; destroy() gỡ listener.

ExportExport PurposeMục đích
new PointerTracker(element?, options?) Defaults to window. Options: velocitySmoothing (0.05 s), follow (0.15), dragThreshold (6 px), tapMaxMs (300).Mặc định là window. Tùy chọn: velocitySmoothing (0.05 s), follow (0.15), dragThreshold (6 px), tapMaxMs (300).
.on(event, listener) 'tap', 'dragStart', 'drag' or 'dragEnd'. Returns the unsubscribe function.'tap', 'dragStart', 'drag' hoặc 'dragEnd'. Trả về hàm hủy đăng ký.
.position, .ndc, .uv CSS px from the top-left, −1…1 with y up, and 0…1 with y up.CSS px tính từ góc trên bên trái, −1…1 với y hướng lên, và 0…1 với y hướng lên.

update(deltaMs), destroy() Per-frame easing; removes listeners.Ease theo khung hình; gỡ listener.
pointerToPlane(ndc, camera, plane, out?) The point where the ray through ndc meets the plane, or null.Điểm mà tia đi qua ndc gặp mặt phẳng, hoặc null.
Interaction3D, interaction3d() Raycasts the pointer against meshes and reports hits.Raycast con trỏ lên các mesh và báo cáo các lần trúng.

Render pipelinePipeline render

createPipeline owns a WebGL 2 canvas, an MSAA scene buffer (half-float with hdr), a composite or post stack, and pixel-space overlays. A pipeline in container mode sizes to a host element, which suits embedded scenes. dispose() releases everything the pipeline owns and is idempotent; rendering after it throws DisposedError. createPipeline sở hữu một canvas WebGL 2, một scene buffer MSAA (half-float khi có hdr), một composite hoặc post stack, và các overlay theo pixel. Pipeline ở chế độ container sẽ co theo phần tử host, phù hợp với cảnh nhúng. dispose() giải phóng mọi thứ pipeline sở hữu và có tính idempotent; render sau đó sẽ ném DisposedError.

ExportExport PurposeMục đích
createPipeline(parent, options?) Options: sizeMode ('viewport' default, or 'container'), clearColor, samples (default 4), hdr (default false), flipMirroredWinding (default true).Tùy chọn: sizeMode ('viewport' mặc định, hoặc 'container'), clearColor, samples (mặc định 4), hdr (mặc định false), flipMirroredWinding (mặc định true).
pipeline.scene, uiScene, uiCamera, beforePassesScene Scene graphs. uiScene with uiCamera is the overlay pass; beforePassesScene is a pixel-space overlay drawn into the scene buffer before the composite.Scene graph. uiScene cùng uiCamera là pass overlay; beforePassesScene là overlay theo pixel được vẽ vào scene buffer trước composite.
pipeline.size, dpr, status Logical size, current pixel ratio, and 'ready' | 'lost' | 'disposed'.Kích thước logic, tỷ lệ pixel hiện tại, và 'ready' | 'lost' | 'disposed'.
render(camera) Draws one frame.Vẽ một khung hình.
setPost(stack | null), setComposite(material) Replaces the final pass. The caller owns the stack; detach it before disposing it.Thay pass cuối cùng. Caller sở hữu stack; hãy gỡ nó ra trước khi dispose.
setPixelRatio(dpr) Resizes the canvas, scene buffer and post stack. Used by adaptive quality.Thay đổi kích thước canvas, scene buffer và post stack. Chất lượng thích ứng dùng hàm này.

registerOffscreenPass(object) Includes a full-screen pass that renders outside the scenes in warmUp.Đưa một pass toàn màn hình render ngoài các scene vào warmUp.

Hiện fallback khi WebGL 2 không khả dụng hoặc bị mất, và ẩn canvas khỏi công nghệ hỗ trợ.

Shaders and materialsShader và vật liệu

Shaders live in one bundle file. A plain entry is a chunk that other sources pull in with #require(name). Entries with #!SHADER: Name.vs and Name.fs become shader programs. #test condition blocks are kept or dropped by an evaluator you supply. createShaderMaterial builds a GLSL ES 3.00 RawShaderMaterial and provides time, timeScale, resolution, cameraQuaternion and normalMatrixWorld. Shader nằm trong một file bundle. Entry thường là một chunk mà các source khác kéo vào bằng #require(name). Entry có #!SHADER: Name.vs và Name.fs trở thành shader program. Khối #test condition được giữ hoặc bỏ bởi một evaluator do bạn cung cấp. createShaderMaterial tạo một RawShaderMaterial GLSL ES 3.00 và cung cấp time, timeScale, resolution, cameraQuaternion và normalMatrixWorld.

PostStack xếp chuỗi các pass lên scene buffer. Mỗi pass là một PostPass với tùy chọn riêng và cờ enabled. Stack được gắn bằng pipeline.setPost.

PhysicsVật lý

Closed-form springs and Verlet simulation are in the root entry. Rigid bodies are in the subpath, so applications that do not need them never load Rapier. Lò xo dạng closed-form và mô phỏng Verlet nằm trong root entry. Rigid body nằm trong subpath, nên ứng dụng không cần chúng sẽ không bao giờ tải Rapier.

RouterRouter

Router maps paths to views and runs each navigation as an ordered, abortable transition. A newer navigation aborts an older one. Views are created once per route and may load their code lazily. Router ánh xạ đường dẫn tới view và chạy mỗi lần điều hướng như một transition có thứ tự, có thể hủy. Điều hướng mới hơn sẽ hủy điều hướng cũ hơn. View được tạo một lần cho mỗi route và có thể tải code một cách lười biếng.

Quality and motionChất lượng và chuyển động

Classify the GPU once, then let QualityManager move between the levels you define as frame times change. Each level has a name and a pixel ratio, and can carry any other fields your scene needs. The reduced-motion policy is global and follows the OS unless you set it. Phân loại GPU một lần, rồi để QualityManager chuyển giữa các level bạn định nghĩa khi thời gian khung hình thay đổi. Mỗi level có tên và tỷ lệ pixel, và có thể mang thêm bất kỳ trường nào scene cần. Chính sách giảm chuyển động là toàn cục và theo hệ điều hành trừ khi bạn đặt khác.
